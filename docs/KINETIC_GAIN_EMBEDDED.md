# Kinetic Gain Embedded — tie-back

## What this repo demonstrates

This repo demonstrates the **evidence-packaged submission** primitive — regulatory comment intake tied to obligation mapping, approval blockers, and operator-safe escalation across regulated workflows.

## How Kinetic Gain Embedded extends it

Kinetic Gain Embedded is security-first embedded analytics for B2B SaaS.
It extends this primitive to obligation-aware and approval-aware in-product analytics for regulated workflows, procurement, and compliance operations, wrapped in:

- signed JWT authentication
- semantic-layer row-level security (RLS)
- read-only data connectors
- AST SQL validation
- append-only audit events
